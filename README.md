# 🔍🦴 Ryley's Mystery Inc. Strategic Trap Operations
**Student:** Ryley Carlson
**Course:** CSC372 | Module 5 Critical Thinking Assignment
**Date:** April 5, 2026

This program is a recursive, narrative-driven console application built in Java. It simulates a high-stakes snack retrieval mission for the Mystery Inc. gang, featuring deep mathematical recursion, randomized hazards, and an immersive "unmasking" finale.

### ✨ Program Features
* **Deep Recursive Logic:** Implements a sophisticated recursive method to calculate the product of exactly five snack values required to bait a ghost trap.
* **Dynamic Ghost Encounters:** Features a 35% probability "Ghost Trigger" that can appear at any stage of the recursion, forcing an immediate tactical retreat (mission failure).
* **Short-Circuit Safety:** Built-in logic to detect "zero-value" inputs immediately, preventing unnecessary calculations and triggering a thematic failure sequence.
* **Thematic ASCII Art:** Features custom ASCII renderings of the Mystery Machine and the Green Phantom to enhance the storytelling experience.
* **Robust Input Validation:** Utilizes `InputMismatchException` handling (the "Red Herring" check) to ensure only valid numeric snack values are processed.
* **The Big Reveal:** A scripted unmasking sequence that concludes successful missions by revealing the true identities of the phantoms: Cosgood Creeps and Cuthbert Crawls.

### 🖥️ Usage Instructions
* **Initiate Mission:** Upon launch, the Mystery Machine will deploy. Follow the on-screen prompts from Fred, Daphne, and Velma.
* **Analyze Boxes:** Enter numeric values for each of the 5 Scooby Snack boxes. These values represent the "snack-power" needed for the trap.
* **Avoid Phantoms:** If a ghost appears during the process, the mission ends. You must restart to try for a successful capture.
* **Calculate Product:** If you successfully input all 5 values without a ghost encounter, the program recursively multiplies the values to set the trap.
* **Unmask Villains:** Achieve a non-zero snack power to trigger the unmasking sequence and see the lawyers behind the masks.
* **Restart Loop:** Use the "yes/no" prompt at the end of the mission to either power down the Mystery Machine or start a new mystery.
